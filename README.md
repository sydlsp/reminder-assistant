# 提醒助手（微信小程序）

第一版包含：

- 任意过去或未来日期的事项排期（日期选择、前后日期切换）
- 手动创建事项
- 读取用户主动复制到剪贴板的微信消息，并预填事项
- 完成与延后事项
- 本地数据存储

## 运行

在微信开发者工具中导入此目录即可预览。当前 `appid` 是 `touristappid`，开发阶段可替换为自己的小程序 AppID。

## 下一步

1. 将 `utils/events.js` 的本地存储迁移到云数据库。
2. 接入登录及用户隔离。
3. 用户授权订阅消息后，使用云函数定时发送到期提醒。
4. 将 `parseClipboard` 的规则解析替换为受控的 AI 结构化解析。

> 小程序只能读取用户主动复制后的剪贴板内容，不能监听或读取个人微信全部会话。
